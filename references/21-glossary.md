# 3. THINGS PEOPLE CONFUSE

| Pair | Difference |
|------|------------|
| Skill vs tool vs toolset vs plugin vs MCP server | **Skill**: markdown procedure (`SKILL.md`, procedural memory). **Tool**: a callable function. **Toolset**: group of tools you enable (`hermes tools`). **Plugin**: Python extension in-process (admitted via `plugins.enabled`). **MCP server**: external process exposing tools via MCP. Skills, plugins, hooks run with agent privileges. |
| Session vs memory vs context file | **Session**: conversation history in `state.db`, searchable. **Memory**: curated durable facts (`MEMORY.md`/`USER.md`), injected each turn. **Context file**: project files like `AGENTS.md` loaded into the prompt. |
| Gateway vs CLI vs dashboard vs API server | **Gateway**: messaging process. **CLI/TUI**: terminal UI. **Dashboard**: web admin (9119). **API server**: OpenAI-compatible HTTP endpoint (8642). Each has separate exposure risk. |
| Profile vs instance vs container | **Profile**: isolated config/skills/memory/secrets under one install. **Instance**: a running process. **Container**: Docker packaging; one container can host many profiles. |
| Hermes Agent vs Hermes models vs Nous Portal | **Agent**: this open-source framework. **Hermes models** (e.g., Hermes 3/4): LLM weights from Nous. **Portal**: subscription for models + Tool Gateway. The agent works with any provider. |
| `terminal.backend: docker` vs running Hermes in Docker | The first sandboxes agent commands; the second packages the whole agent. |
| `hermes backup` vs `hermes profile export` | Whole `HERMES_HOME` zip vs one profile tarball. |
| `/clear`/`/new`/`/reset` vs `/rollback` | Session reset vs filesystem checkpoint restore. |
| Approval deny rules vs hardline blocklist | User-editable globs vs fixed code-shipped floor. |
